# 简单计算器（Python）

一个零依赖的命令行计算器：支持加、减、乘、除、幂（x 的 y 次方）五种运算，带循环菜单与完整的输入错误处理。

## 功能

- 加法、减法、乘法、除法、幂运算（`x` 的 `y` 次方，指数可以是小数，如 `2 ^ 0.5`）
- 操作数支持小数与科学计数法，例如 `-1.5`、`2e3`
- 循环菜单：算完一次自动回到菜单，直到输入 `0` 退出
- 整数结果自动省略多余的 `.0`（输出 `3 + 4 = 7`，而不是 `7.0`）
- 错误处理：非法选项、非数字、空输入、除以 0、`inf / nan`、Ctrl+C、输入流结束，全部友好提示且不崩溃

## 环境要求

- Python 3.8 或更高（开发验证环境：Python 3.8.8，Windows 10）
- 只用标准库 `math`，不需要 `pip install`，不会改动 `requirements.txt`

## 函数说明

| 函数 | 参数 | 返回值 | 异常 |
| --- | --- | --- | --- |
| `add(a, b)` | 两个数字 | `a + b` | 无 |
| `subtract(a, b)` | 两个数字 | `a - b` | 无 |
| `multiply(a, b)` | 两个数字 | `a * b` | 无 |
| `divide(a, b)` | 两个数字 | `a / b`（float） | `b == 0` 时 `ZeroDivisionError("除数不能为 0")` |
| `power(a, b)` | 两个数字（`a` 底数、`b` 指数） | `a ** b`（float） | 负底数 + 非整数指数 → `ValueError`；`a == 0` 且 `b < 0` → `ZeroDivisionError`；结果超出浮点范围 → `OverflowError` |
| `format_number(value)` | float | 去掉多余 `.0` 的字符串；`abs(value) >= 1e16` 时原样输出 | 无 |
| `get_number(prompt)` | 提示语 | float | 空输入 / 非数字 / `inf`、`nan` → `ValueError` |
| `show_menu()` | 无 | 无（打印菜单） | 无 |
| `calculate(choice)` | `"1"` ~ `"5"` | 无（打印算式与结果） | 可能抛 `ValueError`、`ZeroDivisionError`、`OverflowError` |
| `main()` | 无 | 无 | 内部捕获 `EOFError`、`ValueError`、`ZeroDivisionError`、`OverflowError`；`KeyboardInterrupt` 向上抛出 |

## 错误处理清单

| 场景 | 触发方式 | 程序行为（实际输出） |
| --- | --- | --- |
| 非法菜单选项 | 输入 `abc`、空回车或 `9` | `[提示] 无效选项，请输入 1~5 进行运算，或输入 0 退出。` → 回到菜单 |
| 数字格式错误 | 操作数输入 `x` | `[输入错误] [x] 不是有效数字（示例：3、-1.5、2e3），已返回主菜单。` |
| 空输入 | 操作数直接回车 | `[输入错误] 输入不能为空，已返回主菜单。` |
| 除以 0 | 除数输入 `0` | `[计算错误] 除数不能为 0，已返回主菜单。` |
| 底数为负且指数非整数 | 选 `5` 后输入 `-8`、`0.5` | `[输入错误] 负数不能开非整数次方（结果不是实数），已返回主菜单。` |
| `0` 的负数次方 | 选 `5` 后输入 `0`、`-1` | `[计算错误] 0 不能取负数次方，已返回主菜单。` |
| 幂运算结果溢出 | 选 `5` 后输入 `1e200`、`2` | `[计算错误] 结果太大，超出浮点范围（最大约 1.8e308），已返回主菜单。` |
| 特殊值 | 输入 `inf` / `nan` | `[输入错误] 不支持 inf / nan 这类特殊值，已返回主菜单。` |
| Ctrl+C | 运行中按 Ctrl+C | `已通过 Ctrl+C 中断，程序退出。` |
| 输入流结束 | 管道 / 重定向输入结束 | `检测到输入结束（EOF），程序退出。` |

## 设计说明

- 运算函数只负责算数，界面与提示都在主循环里：`divide` 抛异常 → `calculate` 不拦截 → `main` 统一转成友好提示。
- 菜单显示与计算共用一张 `OPERATIONS` 映射表（`"1": ("加法", add, "+")`），避免一长串 `if / elif`。
- `main()` 里的 `try` 只包住可能出错的那一句，不吞掉真正的 bug；`KeyboardInterrupt` 留给最外层统一处理。
- 幂运算特意防"复数结果"：Python 里 `(-8) ** 0.5` 返回的是复数，会让 `format_number` 里的 `math.isfinite` 抛 `TypeError` 直接崩掉，所以 `power()` 先把"负底数 + 非整数指数"挡成友好错误。

## 已知限制 / 可扩展点

- 一次只做二元运算（`a op b`），不支持连续表达式 `1+2*3`。
- 使用 `float`，存在浮点精度问题（`0.1 + 0.2 = 0.30000000000000004`），需要精确小数可换成 `decimal.Decimal`。
- 加减乘的结果绝对值超过 `1e308` 会变成 `inf`（程序不会崩溃，原样显示 `inf`）；幂运算走的是 `OverflowError` → `[计算错误]` 提示，两者处理方式略有不同。
- 幂运算只支持实数结果（不做复数运算）；界面上的 `^` 只是显示符号，程序内部用的是 `**`（Python 里 `^` 是按位异或）。
- 可扩展方向：在 `OPERATIONS` 里加一行即可新增运算（如 `"6": ("取余", modulo, "mod")`），或增加计算历史、括号解析、图形界面。
